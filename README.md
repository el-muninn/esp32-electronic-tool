# esp32-electronic-tool
esp 32 marauder project
custon hardware with esp32 and modfied marauder from justcallmeloko
## Hardware
- ESP32 DevKit V1
- Display OLED SSD1306 (I2C)
- Módulo SD MH (SPI)
- 4 pushbuttons (UP/DOWN/SELECT/BACK)

Ver `/hardware/pinout.md` para o mapeamento completo de pinos.

## Software
- Arduino IDE 2.x
- Bibliotecas: Adafruit_GFX, Adafruit_SSD1306, SD, FS

## Status atual
- [x] Sistema de menu funcional
- [ ] Leitura/gravação em SD
- [ ] Botão UP com defeito intermitente — em investigação
