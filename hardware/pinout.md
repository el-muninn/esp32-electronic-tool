# Pinout — ESP32 DevKit V1

## Display OLED (I2C)
| Sinal | Pino ESP32 |
|-------|-----------|
| SDA   | GPIO21    |
| SCL   | GPIO22    |

## Módulo SD (MH, SPI)
| Sinal | Pino ESP32 |
|-------|-----------|
| CS    | GPIO5     |
| MOSI  | GPIO23    |
| MISO  | GPIO19    |
| SCK   | GPIO18    |
